# EX. No.3.1. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION
## DATE: 02-11-26
## REG NO: 26017329
## NAME : M RAMYA

## AIM:
To construct a 3D solid model of a Fork End component from the given 2D orthographic views (Front, Top, and Right views) using Autodesk Fusion 360.

## REQUIREMENTS:
 • Software. Autodesk Fusion 360 (3D CAD/CAM modeling suite) with an active user account.
 • Operating System. Microsoft Windows 10 (64-bit) operating system.
 • Memory & Graphics. 16 GB RAM paired with integrated or dedicated graphics supporting 1 GB or more VRAM.
 • Internet Connectivity. A stable broadband connection with at least 2.5 Mbps download and 500 Kbps upload speeds for cloud synchronization.
 • Peripherals. A standard keyboard, a three-button scroll mouse, and a display monitor.

## PROCEDURE:
1. Initialize New File: Open Autodesk Fusion 360, create a New Design file, and select the Create Sketch icon from the toolbar.
2. Select Reference Plane: Choose the XY plane (top view) as the primary sketching plane.
3. Create Base 2D Sketch: Use sketching features (Line, Circle, Arc, and Sketch Dimension) to draw the U-shaped fork profile (40 mm overall width, 11 mm arm thickness, 18 mm inner slot, and 52 mm length).
![image](https://user-images.githubusercontent.com/113594316/198551199-8d9b7f6c-6ea7-4d59-8e8c-173f2b5e088f.png)

4. Modify Sketch Geometry: Use sketch modifying features (Trim, Fillet, and Mirror) to clean up intersecting lines and refine the R16 rounded profile.

![image](https://user-images.githubusercontent.com/113594316/198551220-c7aa6694-4427-48e2-9d91-cd7e9615d651.png)

5. Verify Sketch Dimensions: Select the Measure tool from the Inspect menu to verify all dimensions against the given orthographic views.

![image](https://user-images.githubusercontent.com/113594316/198551270-45875855-43a7-4471-af35-bd10cd9dd153.png)

6.	Finalize Sketch: Click the Finish Sketch icon on the top-right toolbar to exit the sketch environment.


![image](https://user-images.githubusercontent.com/113594316/198551309-8d7ac6c8-6740-479f-8186-195c89823fda.png)

7.Extrude Base 3D Model: Select the Extrude option from the Solid > Create menu to convert the 2D fork profile into a 3D solid body with a symmetrical height of 32 mm.

![image](https://user-images.githubusercontent.com/113594316/198551340-fe1f3b48-df79-44ef-a4ae-ff1cd22503ea.png)

8. Create Hole and Cylindrical Shank: Sketch and Extrude (Cut) the Ø16 mm through-hole across the fork arms, then sketch and Extrude the Ø18 mm cylindrical shaft to a length of 32 mm on the back face.

9. Generate ISO Drawing Sheet: After completing the 3D model, switch from the Design workspace to Drawing (From Design) and generate the 2D orthographic views on a drawing sheet as per ISO standards.

![image](https://user-images.githubusercontent.com/113594316/198551370-54509915-ec69-4862-9c17-156d61a83b11.png)
